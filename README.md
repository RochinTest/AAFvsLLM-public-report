# AAFvsLLM — публичный отчёт о закрытии проекта

> **Статус:** проект закрыт 30 июля 2026 года
>
> **Форма публикации:** выводы и посмертный отчёт без исходного кода
>
> **Готовность к применению:** отсутствует

AAFvsLLM создавался как исследовательская архитектура, которая должна была
приобретать, сохранять и комбинировать навыки через специалистов,
контролируемую память и проверяемое продвижение изменений.

Главная гипотеза не получила убедительного подтверждения. Наблюдавшиеся
результаты объясняются изолированными модулями, заранее заданными правилами,
поиском по конечному пространству программ и работой внешнего генератора кода.
Полезная общая пластичность, появление новой операции и самостоятельный
коалиционный интеллект доказаны не были.

Продолжение прежней разработки означало бы защиту уже потраченного времени, а
не проверку жизнеспособной научной идеи. Поэтому проект остановлен, а
отрицательный результат опубликован без попытки переименовать его в успех.

## Итог ключевых гипотез

| Гипотеза | Итог |
|---|---|
| Полезная перестройка общего пространства представлений | Не поддержана |
| Возникновение новой операции в coalition | Не поддержано |
| Новый интеллектуальный примитив | Не поддержан |
| Преимущество над обычным program synthesis | Не показано |
| Экономическое преимущество | Не установлено |
| Готовность к production | Отсутствует |

## Почему здесь нет исходников

Этот репозиторий содержит только проверенные публикационные документы. В нём
нет исполняемого кода, старой Git-истории, runtime-сессий, сырых архивов,
локальных путей, исходников сервера или Turbo-памяти.

Полный исследовательский архив сохранён отдельно в приватном репозитории.
Доступ к коду возможен только после ручного рассмотрения запроса владельцем:
[как запросить доступ](CODE_ACCESS.md).
