# Доступ к исходному коду по запросу

Полный код AAFvsLLM хранится в отдельном приватном forensic-архиве. Этот архив
не выдаётся напрямую: в личном приватном репозитории GitHub приглашённый
collaborator получает не только чтение, но и возможность записи.

После одобрения запроса владелец может подготовить отдельный очищенный экспорт
только нужных компонентов. Если потребуется постоянный Git-доступ, такой
экспорт должен размещаться в отдельном приватном репозитории организации с
ролью `Read`. Старые branches, tags, sessions, серверные компоненты и
Turbo-память в экспорт автоматически не входят.

## Как подать запрос

Создайте [публичный issue по шаблону «Запрос доступа к исходному
коду»](https://github.com/RochinTest/AAFvsLLM-public-report/issues/new?template=code-access.yml)
и укажите:

- свой GitHub username;
- исследовательскую или инженерную цель;
- какие именно компоненты нужны;
- предполагаемое использование результата.

Не публикуйте в issue email, телефон, адрес, токены, пароли, договоры или другую
конфиденциальную информацию.

Владелец рассматривает каждый запрос вручную. Подача запроса не гарантирует
доступ. До выдачи доступа могут быть согласованы отдельные условия просмотра,
использования и распространения. Приватный код предоставляется «как есть», не
является production-ready и не сопровождается обещанием поддержки. Уже
скачанную получателем копию технически отозвать невозможно.
