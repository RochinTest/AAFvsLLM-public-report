# Реестр утверждений и свидетельств

Этот реестр отделяет исходную гипотезу, инженерную реализацию, наблюдение в
конкретном court и широкую интерпретацию. Старый ярлык `PASS` не переносится на
более сильное утверждение и не отменяет позднейшее опровержение.

## Как читать исторические результаты

Для каждого утверждения задаются пять вопросов:

1. Какой именно вход исполнялся?
2. Какой production или laboratory path его обработал?
3. Сохранены ли первичные строки, из которых пересчитывается итог?
4. Что меняется при ablation?
5. Не появился ли позднее witness, противоречащий широкой формулировке?

Если ответ известен только из итогового JSON, результат считается декларацией,
а не независимо пересчитываемым наблюдением. Если court использовал отдельный
режим, его результат не переносится автоматически на normal runtime.

## Исторические ярлыки

В приватном архиве сохранены старые `*_proven` classifications. Они являются
частью истории проекта, но не текущим научным выводом. Настоящий реестр имеет
приоритет для публичного описания.
